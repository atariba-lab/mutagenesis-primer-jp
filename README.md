# 変異導入プライマー設計ツール（Q5方式・計算の途中つき）

部位特異的変異導入（SDM）のプライマーを、**Tm計算の途中まで全部表示しながら**設計するブラウザ用ツールです。

👉 **ツールを開く： https://atariba-lab.github.io/mutagenesis-primer-jp/**

## 特徴

- Q5方式（back-to-back）に対応。Fwdだけが変異を持ち、両プライマーの5′端が背中合わせ、プライマーどうしは重ならない
- 連続した塩基の置換に対応（1塩基〜）
- 最近接法によるTm計算の**途中経過を全部表示**（隣接塩基ごとのΔH・ΔS、塩補正、Tmの式）
- ポリメラーゼ・緩衝液のプリセットを選ぶと、その条件でのTmと目安のアニーリング温度を表示
- 「置換の窓全体を変異として扱う」モードを切り替え可能
- **配列はブラウザの中だけで処理され、外部に送信されません**（単一のHTMLファイル、通信なし）
- 画面内で自己テスト（37項目）を実行できます
- 画面・説明はすべて日本語

## 使い方

1. テンプレート配列を貼り付ける
2. 変異の開始位置と、置換後の塩基を入力する
3. 使うポリメラーゼ・緩衝液を選んで「設計する」

ファイルをダウンロードして、ローカルでブラウザで開いても同じように動きます。

## 前提と限界

- 対象は**Q5方式の連続塩基置換のみ**です。挿入・欠失、アミノ酸入力、バッチ処理、QuikChange方式には対応していません
- FwdのTmは、置換が6塩基未満でミスマッチが文献の表にある組み合わせのとき、文献のパラメータで直接計算します。それ以外（連続ミスマッチ、端から2塩基以内など）は経験的な近似に切り替わります。どちらを使ったかは画面に表示されます
- 目標Tm（56℃）、Tm差の上限（5℃）、5′側10塩基などの既定値は**経験則**です
- アニーリング温度は目安です。実際の条件は、使用するポリメラーゼの製造元が推奨する値を優先してください
- Tris由来の塩の寄与は計算に含めていません
- ヘアピン・ダイマーの判定は簡易的な目安です
- 他の計算ツールとのTmの差は、おおむね1〜2℃です（確認したのは8件のみ）

**注文・実験の前に、変異位置と配列を必ず目視で確認してください。**

## Tm計算の根拠

パラメータ値は以下の論文に記載された数値を使用しています。コードは自作で、他のソフトウェアのコードは取り込んでいません。

- SantaLucia J Jr. *PNAS* 1998;95:1460-1465.（最近接パラメータ、塩補正）
- von Ahsen N, Wittwer CT, Schütz E. *Clin Chem* 2001;47:1956-1961.（Mg²⁺のNa⁺換算）
- Allawi HT & SantaLucia J Jr. *Biochemistry* 1997;36:10581 / 1998;37:2170 / 1998;37:9435; *Nucleic Acids Res* 1998;26:2694（ミスマッチ用パラメータ）
- Peyret N, Seneviratne PA, Allawi HT, SantaLucia J Jr. *Biochemistry* 1999;38:3468-3477（同上）

ミスマッチ用パラメータ表は、手入力による転記ミスを避けるため、Biopython（BSDライセンス）の `Bio.SeqUtils.MeltingTemp.DNA_IMM1` に収載された表を参照しました。コードは流用していません。

なお、プライマー濃度は**プライマーが大過剰にある前提（C<sub>T</sub>）**で計算しています。2本鎖が等濃度にある前提（C<sub>T</sub>/4）を採る実装とは、同じ配列・同じ条件でも 1℃程度の差が出ます。
